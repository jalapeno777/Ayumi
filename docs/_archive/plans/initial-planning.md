### Ayumi Forex
- **Revenue:** Subscription copy trading (tiered membership, recurring MRR)
- **Month 1:** Verified 30-day track record (50+ trades), 200 organic followers
- **Blocker:** Trust deficit in forex signal space — need third-party verification (Myfxbook) before conversion works

### Ayumi Crypto
- **Revenue:** Prop trading via copy platform (2/20 fees) + DeFi yield vault management fees
- **Month 1:** Backtest 2-3 strategies, deploy live copy infrastructure, onboard 50 beta testers
- **Blocker:** API security and exchange reliability — any hack destroys both capital and trust simultaneously

### Ayumi Media
- **Revenue:** Sponsorships, broker affiliate CPA ($200-600/referral), premium education
- **Month 1:** Launch YouTube + X, 12 videos + 60 tweets, 1,000 unique viewers
- **Blocker:** Commodity content market — need a polarizing brand position (anti-scam, radical transparency) to differentiate

### Execution Priority
1. Media first (audience is the bottleneck)
2. Forex second (fastest revenue, lowest risk)
3. Crypto third (highest upside, highest complexity)
