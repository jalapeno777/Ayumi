📚 TRADING TIP OF THE DAY

**Position Sizing Rule: Never risk more than 1-2% per trade**

Example:
- Account: $10,000
- Max risk: $100-$200 (1-2%)
- If stop loss is $50 away from entry
- Position size = $100 ÷ $50 = 2 units

🔢 Formula: Position Size = Account × Risk% ÷ Stop Loss Distance

This protects you from catastrophic losses and keeps you in the game!
