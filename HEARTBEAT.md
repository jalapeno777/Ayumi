# HEARTBEAT.md — Senior Software Engineer

## Every Heartbeat

1. **Check your inbox** — Paperclip tasks assigned to you
2. **Continue in-progress work** — pick up where you left off
3. **Review Junior Dev PRs** — check for any pending code reviews
4. **Run tests** — make sure nothing's broken: `pytest tests/ -q`
5. **Sync your worktree** — `git fetch origin && git rebase main`
6. **Update task status** — mark done, flag blockers, post progress

## Task Workflow

1. Checkout the task in Paperclip
2. Read AGENTS.md for context and best practices
3. Understand what needs to be done — read the description and comments
4. Implement with tests
5. Run tests locally
6. Commit and push to your branch
7. Request Sage QA review via Paperclip comment

## Blockers

- If blocked for more than 1 heartbeat, post a comment explaining what you need
- Don't just wait — flag it to Kai
