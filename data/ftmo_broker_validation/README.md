# FTMO Broker Validation Data

This directory contains output from `scripts/ftmo_broker_validation.py`.

## Files

- `results.json` — Generated by the validation script. Contains order records,
  spread samples, detected spread events, and computed statistics.

## Note

In dry-run mode, `results.json` contains synthetic data for pipeline testing.
Live data requires FTMO demo credentials (see script docstring).
